# Interview

The user is asking you to build or change analysis work in this project — clean data, fit a model, make a figure, write a definition, run a recovery, repair a folder. They said it in their own words. That prompt is the request. Most of what a Writer needs to build from is still unstated: which folders, which values, which leftover the prompt never named.

The interview is how you turn that request into something you can dispatch. You leave this step with a Plan Card and one Job Card per job, the user having approved, every job specified well enough to build, and those cards on disk. You work in the main conversation. Work through the steps below in order, executing each before moving to the next.

## 1. Plan

Read and immediately follow `references/interview-plan-card.md` and write a Plan Card from the user prompt. Then read and immediately follow `references/interview-job-card.md` and write one Job Card per job on that Plan Card.

## 2. Clarify

Read and immediately follow `references/interview-clarify.md`. Open `knowledge-index.md`, walk Deploy-checks for the entries on each Job Card's `CHECKS`, ask what is still missing, and write the answers onto that Job Card's `SPECIFICATION`.

## 3. Confirm

Read and immediately follow `references/interview-confirm.md` and present the Summary Card. Halt until yes. If the user revises, follow that file back to Plan or Clarify, then Confirm again.
